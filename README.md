# 🚀 Om Prakash Samal — Developer Portfolio

A responsive, high-performance developer portfolio built from scratch using pure **HTML5, CSS3, and JavaScript (ES6+)**. This site showcases my full-stack web applications, native Android software, computer vision/AI projects, technical certifications, and corporate internship experiences.

🌐 **Live Demo:** [portfolio-om-red.vercel.app](https://portfolio-om-red.vercel.app)

---

## ✨ Features

- **⚡ Dynamic Intro Preloader:** High-tech percentage loader (`0%` to `100%`) featuring custom visual branding, dynamic system status logs, and smooth reveal transitions.
- **📱 Fully Responsive:** Adaptive mobile & desktop layout designed with zero layout shifts or flickering across all viewports.
- **🔄 Live GitHub API Sync:** Automatically fetches, updates, and displays recent public repositories, stargazers, and topic tags with an offline fallback mechanism.
- **🎓 Course & Certificate Viewer:** Interactive modal system to preview verified certificates (UiPath, IBM, Coursera) directly within the app.
- **🤖 Omex AI Assistant Widget:** Floating interactive chatbot assistant designed to handle quick visitor queries.
- **📄 Document Management:** Direct inline previewing and downloading for resume PDFs across desktop and mobile devices.
- **🎨 Glassmorphic UI/UX:** Dark-mode architecture featuring custom CSS glow effects, interactive cards, and continuous tech-stack tickers.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3 (Flexbox/Grid, CSS Variables, Animations), JavaScript (Vanilla ES6+)
- **APIs & Data:** GitHub REST API, `localStorage`
- **Deployment & Hosting:** Vercel
